# MetroPT3.csv 파일 분석 결과
## 📊 MetroPT-3 데이터 컬럼 설명

MetroPT-3 데이터셋은 철도 차량의 **공기 생산 장치(APU, Air Production Unit)** 에서 수집된 시계열 센서 데이터입니다.  
압력, 오일 온도, 모터 전류 등의 **아날로그 센서 7개**와 장치의 작동 상태를 나타내는 **디지털 신호 8개**로 구성되어 있습니다.

### 🕐 시간 정보

| 컬럼명 | 설명 |
|---|---|
| `timestamp` | 센서 데이터가 측정된 날짜와 시간 |

### 📈 아날로그 센서

| 컬럼명 | 단위 | 설명 |
|---|---:|---|
| `TP2` | bar | 압축기에서 측정된 공기 압력 |
| `TP3` | bar | 공압 패널(Pneumatic Panel)에서 생성되는 압력 |
| `H1` | bar | 사이클론 분리 필터가 배출될 때 발생하는 압력 강하에 따른 압력 |
| `DV_pressure` | bar | 에어 드라이어 타워가 공기를 배출할 때 발생하는 압력 강하. 값이 0이면 압축기가 부하 상태로 작동 중임을 나타냄 |
| `Reservoirs` | bar | 공기 저장 탱크(Reservoir) 후단의 압력. 정상적으로 TP3 압력과 비슷한 값을 가짐 |
| `Oil_temperature` | °C | 압축기 내부 오일의 온도 |
| `Motor_current` | A | 3상 모터 한 상의 전류. 압축기 작동 상태에 따라 전류값이 달라짐 |

### ⚙️ 디지털 신호

| 컬럼명 | 설명 |
|---|---|
| `COMP` | 압축기 흡입 밸브의 전기 신호. 활성화되면 압축기가 정지했거나 무부하 상태임을 나타냄 |
| `DV_eletric` | 압축기 출구 밸브를 제어하는 전기 신호. 활성화되면 압축기가 부하 상태로 작동 중임을 나타냄 |
| `Towers` | 공기를 건조하는 에어 드라이어 타워를 구분하는 신호. 0이면 Tower 1, 1이면 Tower 2가 작동 |
| `MPG` | APU 압력이 8.2 bar 아래로 떨어질 때 압축기를 부하 상태로 작동시키는 전기 신호 |
| `LPS` | 압력이 7 bar 아래로 떨어질 때 활성화되는 저압 감지 신호 |
| `Pressure_switch` | 에어 드라이어 타워의 배출을 감지하는 전기 신호 |
| `Oil_level` | 압축기의 오일 부족을 감지하는 신호. 오일이 기준보다 낮으면 활성화됨 |
| `Caudal_impulses` | APU에서 저장 탱크로 흐르는 공기량에 따라 발생하는 유량계 펄스 신호 |
